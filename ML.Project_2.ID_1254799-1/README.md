# Linear regression model

### Summary: This project focuses on supervised learning, particularly linear models, regularization techniques, overfitting, underfitting, and metrics for quality estimation.

Этот проект посвящен линейным моделям машинного обучения для решения задач регрессии. В ходе этого обучающего проекта я глубоко изучила линейную регрессию( аналитический метод, приближенный численный метод(с градиентным спуском)), регуляризация(L1-Lasso, L2-Ridge, ElasticNet), нормализацию(MinMax Scaler, standard scaler), проблемы переобучения (overfitting) и недообучения (underfitting), работу с полиномиальными признаками, метрики(MAE, R², RMSE). <br>
Я провела предобработку данных, убрав выбросы, закодировав категориальную переменную и создав 22 новых бинарных признака из колонки "Features". Для большего понимания темы, реализовала вручную классы для LinearRegression, Ridge, Lasso, ElasticNet с использованием аналитического решения (через матричные операции) и градиентного спуска, а также написала функцию, вычисляющую R2-score и две функции для нормализации(MinMax Scaler и standard scaler).  <br>
Для оценки качества работы моих моделей сравнила мои реализации с реализацией из библиотеки sklearn, сравнив метрики MAE, RMSE, R² на тренировочных и тестовых данных, а также проанализировала влияние регуляризации
