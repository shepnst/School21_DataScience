# Machine learning introduction

Summary: This project is an introduction to machine learning and especially to primary data analysis with some practical basics.

Этот проект представляет собой введение в машинное обучение с акцентом на анализ данных и построение моделей. Основная цель — предсказать стоимость аренды квартир на основе выделенных признаков, используя датасет с Kaggle. После краткой теоретической части, я выбрала target и проанализировала данные с Kaggle: изучила структуру и основные статистические характеристики, провела статистический анализ, в котором проанализировала распределение целевой переменной (price) с помощью гистограмм и boxplot, после чего очистила данные от выбросов. Затем приступила к работе с признаками: кодировка категориальной переменной interest_level, проанализировала корреляции между признаками с помощью тепловой карты, после чего оставила необходимые признаки и подготовила датасет для обучения моделей, разделив его на обучающие и тестовые выборки. После чего для всех моделей(Линейная регрессия, решающее дерево и "наивные" модели (предсказание средним/медианой)) были подсчитаны и сравнены метрики MAE и RMSE  для предсказанной цены квартиры
