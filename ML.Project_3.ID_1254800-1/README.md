### **ML Project 3**
**Этот проект посвящен**: <br>
1. Различным схемам разделения данных (train/validation/test), кросс-валидации и её типам (K-Fold, Grouped, Stratified, Time Series), борьба с переобучением и информационной утечкой <br>
2. Оптимизации гиперпараметров: Grid Search, Random Search, Bayesian optimization (Optuna), поиску оптимальных параметров для моделей, сравнению методов оптимизации<br>
3. Feature selection: Lasso, корреляционный анализ, permutation importance, SHAP
